# ☯️ 易经·赛博起卦 

基于 React 实现的数字起卦工具。通过模拟传统的“三钱法”，自动生成本卦与变卦，并结合详细的卦象数据提供事业、经商等维度的深度解析。

# 应用价值

- **即时决策辅助**：通过模拟传统“三钱法”，用户只需几秒钟即可完成起卦，为日常生活中的决策提供一种基于传统哲学的心理暗示与逻辑参考。

- **一站式解析**：内置完整的 64 卦经文与多维度解析（事业、经商、求名等），无需翻阅古籍即可直观获取卦象反馈，极大地提升了传统文化工具的可用性。


## ✨ 功能特点
- **三钱法模拟**：真实模拟正反面概率。
- **动态起爻**：六爻递进，沉浸式起卦体验。
- **64卦全解析**：集成完整的卦名、象曰及多维度人生建议。

## 🛠️ 技术栈
- React + Lucide Icons
- JSON 数据解析
- CSS 动画
